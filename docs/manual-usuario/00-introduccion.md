# Raíz · Manual de usuario del backoffice

**Backoffice · Ingeniería Para la Alimentación**

Guía para administradores y analistas. Los pasos y capturas de este manual corresponden a el panel web.

## Cómo usar esta guía

Comenzá por Acceso y seguí el capítulo de la tarea que necesitás realizar. Comprobá tu rol y el establecimiento elegido si una acción no aparece.

| Capítulo                                   | Qué vas a poder hacer                                                  |
| ------------------------------------------ | ---------------------------------------------------------------------- |
| [Acceso y trabajo en equipo](01-acceso.md) | Ingresar al panel, gestionar solicitudes, usuarios y establecimientos. |
| [Talla y Peso](02-talla-y-peso.md)         | Consultar sujetos, mediciones, evolución y exportaciones.              |
| [Encuestas](03-encuestas.md)               | Crear y activar encuestas, consultar y exportar respuestas.            |
| [Nutrir](04-nutrir.md)                     | Consultar stock, registrar movimientos y revisar el historial.         |

## Qué significa cada nombre

| Nombre                                     | Significado en Raíz                                                                             |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------- |
| Establecimiento o comedor                  | Lugar al que se vinculan las actividades y los movimientos de alimentos.                        |
| Sujeto                                     | Persona registrada para realizar su seguimiento.                                                |
| Relevador / Responsable de establecimiento | Persona que carga datos desde la app.                                                           |
| Analista                                   | Integrante del equipo que trabaja con relevamientos desde el backoffice.                        |
| Administrador                              | Persona que además gestiona cuentas, solicitudes y establecimientos.                            |
| Sincronizar                                | Enviar al sistema los registros guardados en el teléfono.                                       |
| Perfil del establecimiento                 | Ficha sobre funcionamiento, asistentes, alimentación y comunidad; distinta del perfil personal. |

## Antes de empezar

Las opciones dependen de tu rol y del acceso al establecimiento. Los datos cargados desde teléfonos aparecen cuando terminan de sincronizarse; si falta una carga, coordiná con quien la realizó y revisá los filtros.
