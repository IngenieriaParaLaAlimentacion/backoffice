# Backoffice

Developed using NextJS and  UI.

## System Requirements

Install the following tools first:

- Node.js **24 LTS**
- npm (comes with Node.js)

### Install Node.js

Install Node.js from the official page: [nodejs.org/en/download](https://nodejs.org/en/download).

For local development, using `nvm` is recommended. A Docker container might be available to run the app soon.

## Run the app

Install dependencies first:

```bash
npm install
```

Run server in dev mode:

```bash
npm run dev
```

## Run tests

Run the full test suite locally with:

```bash
npm run test
```
